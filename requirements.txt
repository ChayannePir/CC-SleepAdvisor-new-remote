# Ce projet est une application PHP (Symfony). Un fichier `requirements.txt` Python n'est pas approprié
# pour installer les dépendances principales de l'application.
#
# Prérequis système (à installer en dehors d'un venv Python) :
# - PHP >= 8.2
# - Extensions PHP recommandées : ext-ctype, ext-iconv, pdo_mysql (ou pdo_sqlite si vous utilisez sqlite), mbstring, intl, xml, zip
# - Composer (gestionnaire de dépendances PHP)
# - MySQL / MariaDB ou autre base prise en charge
# - (optionnel) Symfony CLI
#
# Commandes recommandées pour démarrer le projet (PowerShell) :
# 1) Se placer dans le répertoire du projet
#    cd "C:\Users\chaya\IdeaProjects\SleepAdvisor"
#
# 2) Installer les dépendances PHP via Composer
#    composer install
#
# 3) Copier le fichier d'environnement et l'éditer
#    Copy-Item ".env.example" ".env"
#    # puis modifier DATABASE_URL et autres variables dans .env
#
# 4) Créer la base de données et exécuter les migrations
#    php bin/console doctrine:database:create
#    php bin/console doctrine:migrations:migrate --no-interaction
#
# 5) Lancer le serveur de développement
#    symfony serve    # si Symfony CLI installé
#    # ou
#    php -S localhost:8000 -t public/
#
# Si vous souhaitez malgré tout utiliser un environnement Python (venv) pour des outils externes
# (scripts d'automatisation, linters, utilitaires), créez un venv et ajoutez ici les paquets Python
# que vous souhaitez. Exemple minimal pour des outils d'aide (aucun n'est requis par le projet) :
#
# # Exemple optionnel (décommentez si utile) :
# # requests==2.31.0
# # python-dotenv==1.0.0
# # pre-commit==4.4.0
#
# Récapitulatif : n'utilisez pas pip/requirements.txt pour installer les dépendances de l'appli elle-même.
# Utilisez composer (voir INSTALLATION.md pour les étapes complètes).
